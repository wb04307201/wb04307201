### 写作要求

- **JDK 版本必标**：所有参数、行为、JVM 特性必须标注适用 JDK 版本（默认 HotSpot）
- **GC 日志示范**：调优类文章必须包含至少 1 段真实 GC 日志（含 `-Xlog` 格式）
- **参数三段式**：每个调优参数按「默认值 → 调整值 → 业务依据」三段书写
- **LTS 版本对比**：跨版本特性必须给出 JDK 8 / 11 / 17 / 21 / 25 至少 3 个 LTS 对比
- **G1/ZGC 优先**：JDK 9+ 默认 G1，JDK 15+ 推荐 ZGC；其他收集器仅作历史背景
