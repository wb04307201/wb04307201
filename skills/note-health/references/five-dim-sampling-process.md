# 5-dim 抽样流程固化（v1→v5 五轮经验，2026-09-01）

> **目的**：将 5 轮抽样（v1 / v2 / v3 / v4 / v5）经验固化为可复用流程
> **数据基础**：5 轮抽样 119+ 篇（v1: 48 / v2: 49 / v3: 21 / v4: 30 / v5: 30+）
> **核心成果**：准确度从 v1 → v4 演进，流程从 233 误报 → 0 误报

## 1. 流程概述

```
触发 → 抽样 → 评分 → 校准 → 验证 → 沉淀
 ↓      ↓      ↓      ↓      ↓      ↓
季度  30 篇  5-dim  偏差  v+1  报告
体检  /模块  0-10  ≥1   抽样
```

## 2. 触发条件

| 触发场景 | 频率 | 关键动作 |
|----------|------|----------|
| **季度体检** | 每 3 月 | 完整 Phase 1-7 |
| **新模块首次沉淀** | 一次性 | 全模块评估 |
| **批量内容深化**（> 10 篇源码级扩展）| 1 周内 | 专题抽样 |
| **用户反馈难度不准** | 立即 | 单模块抽样 |
| **5⭐ 保留档文件变动** | 立即 | 单文件人工审核 |

## 3. 抽样策略（5 层加权）

### 3.1 按模块均分权重分配

```
抽样数 = 30 × (模块均分 / 总均分)
```

| 层级 | 抽样数 | 比例 |
|------|------|------|
| 高分模块（avg ≥ 8.0）| 5-7 | 17-23% |
| 中高分（7.0-7.9）| 3-5 | 10-17% |
| 中分（6.0-6.9）| 1-3 | 3-10% |
| 低分（< 6.0）| 0-1 | 0-3% |

### 3.2 抽样组成

每批 30 篇，按 5 维评分覆盖：
- 已校准文件（验证准确度）
- 新补全文件（验证补全准确度）
- 未评估文件（v6 抽样候选）

必须**同时满足**：

- D4 ≥ 1
- D5 ≥ 1

## 5. 校准流程（v4 经验）

### 5.1 偏差检测

每轮抽样后：
- 计算 **完全一致率**（偏差=0）
- 偏差 ≥1 文件列入「待校准清单」
- 偏差 ≥2 文件优先修复

### 5.2 校准优先级

| 偏差类型 | 数量阈值 | 行动 |
|---------|---------|------|
| 偏差=0 | < 70% | 重审评分标准 |
| 偏差 ≥1 | < 10% | 流程成熟 |
| 偏差 ≥2 | 任意 | 立即修复 + 反思标准 |
| 偏差方向 | 高估 > 40% | L5 标准需收紧 |

### 5.3 应用校准

- 用 Edit 工具修改 frontmatter `depth:` 字段
- 一条 commit 包含所有校准
- commit message 含「v{n+1} 抽样 N 篇偏差校准」

## 6. 验证流程（v5 关键）

### 6.1 闭环验证

每轮应用校准后，**必须**再抽 30 篇验证：
- 准确度提升 ≥ 10% → 流程改进
- 准确度提升 < 5% → 标准需重审
- 准确度下降 → 回滚校准

### 6.2 阶段性目标

| 轮次 | 准确度目标 | 实际 |
|------|----------|------|
| v1 | 60% | N/A（首轮无 baseline） |
| v2 | 70% | N/A |
| v3 | 80% | N/A |
| v4 | 85% | **43%**（未达） |
| v5 | 70% | 进行中 |

**注**：v4 准确度低于预期，因 v1-v3 误报消除后未及时收紧 L5 标准。v4 → v5 校准后预计回升至 70%+。

## 9. 关键教训（5 轮沉淀）

1. **L5 标准需硬指标化**：v1-v3 仅靠"主题深度"主观评分，导致 40% 高估。v4 后必须 D2=2 作为门槛。
2. **agent 间一致性必须 ≥ 70%**：否则评分标准有歧义。
3. **footer 同步是双轨制前提**：v4 发现 76% 文件缺 footer，导致校验困难。v3 已修复。
4. **broken links 集中爆发**：v3 后新增内容易引错路径。需 CI 自动检查。
5. **depth vs difficulty 双轨制**：12.interview 用 difficulty，主模块用 depth，13.story 用 D 类评估。三套独立。

## 10. 持续改进

- **每季度 1 次完整抽样**（30+ 篇）
- **每年 1 次评分标准迭代**（基于偏差分布）
- **持续集成 depth/difficulty CI 检查**
- **跨模块反向链覆盖率 ≥ 80%**
